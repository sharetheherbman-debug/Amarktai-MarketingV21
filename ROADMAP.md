# Roadmap

AmarktAI Marketing platform development roadmap.

## Completed

### Phase 1: Foundation (v0.1.0)
- [x] Turborepo monorepo setup
- [x] Express + TypeScript backend
- [x] Next.js 15 frontend with App Router
- [x] PostgreSQL database with migrations
- [x] Authentication and authorization (JWT, RBAC)
- [x] Docker Compose infrastructure
- [x] Shared UI component library

### Milestone 1: AI Core (v0.2.0)
- [x] Agent orchestration system
- [x] Prompt library with versioning and rollback
- [x] Brand DNA system
- [x] Tool registry
- [x] Context engine for AI operations
- [x] Multi-provider AI routing (GenX, Together, DeepInfra)
- [x] Memory architecture (business, conversation)

### Milestone 2: Research & Knowledge (v0.3.0)
- [x] Knowledge source management (website, document, API)
- [x] Website crawler with text chunking
- [x] Vector search with pgvector embeddings
- [x] Competitor monitoring with change detection
- [x] Trend monitoring with alerts
- [x] Knowledge, Competitor, Trend frontend pages
